# SteamVR integration research

Research performed 2026-11-14 against [Valve's OpenVR driver documentation](https://github.com/ValveSoftware/openvr/blob/0924064316de3effbcd1acf1e309182a2deb1c05/docs/Driver_API_Documentation.md), and the official sources linked below.

- A server driver exports `HmdDriverFactory`, implements `IServerTrackedDeviceProvider`, and registers each long-lived `ITrackedDeviceServerDriver` using `TrackedDeviceAdded` with class `GenericTracker` and an immutable unique serial. The provider returns the SDK interface-version list. Report poses with `TrackedDevicePoseUpdated`; runtime prediction is limited to about 100 ms.
- Set `activateMultipleDrivers` to allow an additional driver while the headset's driver is active. Tracker roles are configured by users in SteamVR's Manage Trackers screen. Valve lists waist, chest, left/right knees and left/right feet among the supported roles. Do not silently rewrite the user's tracker assignments.
- OpenVR uses right-handed coordinates (+X right, +Y up, +Z backward) and meters. `GetRawTrackedDevicePoses` exposes the HMD at index 0 and other devices at their indices. **Raw tracking spaces are defined per originating driver.** Merely using identity driver-to-world transforms does not establish alignment with Steam Link's physical tracking space: an explicit, verified transformation or a common runtime space is needed. Head and hand poses must not be assumed comparable merely because the API returns them together.
- Poses must be finite, normalized, fresh, and accompanied by accurate validity and connection flags. A stale or uncalibrated estimate must be invalidated rather than displayed as a valid body pose. Six body-mounted IMUs without absolute position references cannot independently measure absolute position or prevent heading drift.
- [VRChat's FBT documentation](https://docs.vrchat.com/docs/full-body-tracking) describes feet, knees, hip, chest, elbows/shoulders, and up to eight additional trackers. It recommends SteamVR role assignment and in-game calibration. Waist, chest, knees and feet are plausible virtual output roles, but calf-mounted IMUs do not directly observe foot orientation/position; these are estimates, and VRChat compatibility must be tested.
- [Valve's 2024 Steam Link beta announcement](https://store.steampowered.com/news/posts/?appids=250820&enddate=1724276524&feed=steam_community_announcements) states Quest hand tracking is forwarded through SteamVR skeletal input and OpenXR `XR_EXT_hand_tracking`, while noting SteamVR support was limited and dependent on bindings at that time. The tracker driver must leave the headset and controllers/hand devices owned by Steam Link. Current game-specific support requires verification in the user's setup; tracker support does not guarantee finger tracking.

No driver registration, SteamVR configuration changes, or live-hardware verification have been performed by this research.
